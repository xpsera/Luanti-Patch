# Luanti-Patch Prototype
 
**A modified version of Luanti maintained by xpusera.**
 
This build includes custom mechanics, features, and engine changes. While most features have been tested by the developer, the project has not yet received extensive testing from the wider modding community. Bugs, compatibility issues, and unfinished behavior may still exist.
 
## Source Code Availability
 
The source code is currently **not publicly available** for Prototype releases. Since the project is still experimental and undergoing active development, changes may be unstable, incomplete, or insufficiently tested.
 
Source code will be published or updated with releases that are considered **stable**. Prototype-tagged releases are intended for testing and evaluation and may contain unfinished or unverified changes.
